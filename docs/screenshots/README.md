# 截图目录 · Screenshots

主 README 引用了本目录下的以下截图。在 DSH 的「模型 Ultra」页面截图后，用同名文件替换即可自动生效：

| 文件名 | 页面 | 建议内容 |
|--------|------|----------|
| `dashboard.png` | 仪表盘 | 全部 / 已启用 / 已禁用分段、新建向导入口、状态色条卡片 |
| `editor.png`    | 编辑器 | 概览 / 请求头 / 模型 / 思考强度 / 测试 标签页 |
| `models.png`    | 模型   | 远端模型发现 + 全选/反选 + 批量写入 |
| `test.png`      | 测试   | 单模型连通性测试结果（延迟 + 回复） |
| `routes.png`    | 智能路由 | 路由台 / 组合提供商 / 观测台 / 探活 |

可选补充（当前缺失，欢迎替换 / 新增）：`thinking.png`（思考强度档位表与预设）、`openrouter.png`（OpenRouter 模式 / 量化 / 归属头 / 自检）。

截图建议：浅色或深色主题任一，宽度 ≥ 1200px，PNG 格式，**避免截入真实 API Key、私有网关地址或个人信息**。
